### 2.3 Recruitment Timeline

```
Week 1:
- [ ] Draft recruitment messages
- [ ] Set up email list/newsletter signup
- [ ] Create social media posts
- [ ] Identify community partners to ask

Week 2:
- [ ] Send first recruitment wave (email, social, partners)
- [ ] Monitor signup form, track which channels drive signups
- [ ] Follow up with question answers

Week 3:
- [ ] Send second recruitment wave (emphasize deadline)
- [ ] Outreach to key individuals if signups lag
- [ ] Update recruitment materials based on early response

Week 4:
- [ ] Final recruitment push (deadline approaching)
- [ ] Confirm all signups, gather volunteer details
- [ ] Assign roles based on interests/abilities
```

### 5.2 Safety Checklist

```
Pre-Event:
☐ Scout location for hazards (broken glass, sharp objects, etc.)
☐ Verify park is accessible for volunteers
☐ Confirm water/bathroom access
☐ Check weather forecast (and backup plan)
☐ Brief event lead on first aid procedures

Event Day:
☐ Gather volunteers before starting
☐ Safety briefing (what not to touch, proper glove use, heat breaks)
☐ First aid kit accessible
☐ Adequate water/shade breaks
☐ Supervision of any youth volunteers
☐ Emergency contact numbers shared

Post-Event:
☐ Check all volunteers for injuries
☐ Proper hand-washing facilities/availability
☐ Safe trash disposal completed
```
